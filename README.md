# Project Wisp 🌿

An original cozy fantasy virtual companion that begins as a mystery egg.

## Play
Open `index.html` locally in a browser. No build tools required.

## Version 0.1
- Warm, sing to and rest with your egg.
- Raise warmth and trust to hatch Mossling.
- Exchange scripted messages.
- Automatically save progress and recent messages to localStorage.
- Responsive phone-friendly layout.

## Current limitations
This is **not yet real conversational AI**. The dialogue uses scripted responses. The creature currently uses an emoji placeholder rather than custom artwork. Saved data is stored only in this browser and can be cleared.

## Next milestones
1. Original illustrated creature and egg artwork.
2. Secure backend for model-powered conversations; no API secrets in browser code.
3. Opt-in memory summaries, user memory controls, and deletion.
4. Optional accounts and syncing.
5. More activities, forest exploration and evolving personality.

To publish this static prototype, go to Settings → Pages → Deploy from a branch → main / root.
